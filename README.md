# UPX Medica website

A responsive, animated coming-soon website built with HTML, CSS and plain JavaScript. Optimised for small phones, large phones, tablets, laptops and widescreen desktops; supports reduced-motion preferences.

## Preview
Open `index.html` in your browser.

## Publish with GitHub Pages
1. Create a GitHub repository (e.g. `upx-medica-site`).
2. Upload `index.html`, `style.css`, `script.js`, and `favicon.svg` into the repository root.
3. Under Settings > Pages, choose Deploy from a branch, `main`, and `/ (root)`.
4. Once deployment completes, the site will be live at your GitHub Pages URL.
5. For a custom domain, configure both the repository Pages custom domain and DNS records at your domain registrar.

## Before launch
- Replace aspirational copy once your actual trading scope and authorisations are confirmed.
- External Google Fonts require an internet connection; system fonts are provided as fallbacks.

The website does not claim that UPX Medica currently holds an MHRA wholesale distribution authorisation.
